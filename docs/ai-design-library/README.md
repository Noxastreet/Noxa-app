# NOXA AI Design Library

Эта папка — отдельная рабочая библиотека для промптов, дизайнерских инструкций, UX-правил, исследовательских заметок и материалов наставничества по интерфейсу NOXA.

## Границы

Эта библиотека:

- не заменяет корневой `README.md`;
- не изменяет инженерные правила проекта;
- не является источником runtime-конфигурации;
- не заменяет существующие документы по архитектуре, безопасности или релизам;
- используется как рабочая среда для формирования продуктового и дизайнерского мышления NOXA.

## Структура

1. `01-product-vision.md` — назначение продукта и пользовательская ценность.
2. `02-ux-philosophy.md` — ощущения, поведение и принципы взаимодействия.
3. `03-interface-principles.md` — правила компоновки, иерархии и управления.
4. `04-map-experience.md` — отдельные правила главного экрана карты.
5. `05-community-experience.md` — профили, Garage, Crews, Events и социальная часть.
6. `06-motion-language.md` — правила анимаций и переходов.
7. `07-design-research.md` — как изучать референсы без слепого копирования.
8. `08-ai-prompt-library.md` — специализированные промпты для ChatGPT, Codex и других ИИ.
9. `09-design-review.md` — критерии проверки экранов и компонентов.
10. `10-decision-log.md` — журнал принятых дизайнерских решений.

## Рабочий процесс

Каждая тема проходит по цепочке:

1. мысль владельца продукта;
2. уточняющие вопросы;
3. формулировка продуктового намерения;
4. UX-требования;
5. прототип;
6. критика;
7. реализация;
8. проверка на реальном устройстве.

Ни одна страница этой библиотеки не считается окончательной, пока решение не подтверждено реальным поведением приложения и пользовательским тестированием.
